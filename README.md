# 🚀 Quantum Nest | Cosmic Insights

Quantum Nest is a high-fidelity, intelligent gateway to the universe. It serves as a unified command center for exploring deep-space archives, planetary libraries, and NASA scientific data through a refined, human-centric interface.

## 🌌 Mission Modules

- **Solar System Exploration**: Comprehensive archives of planets and gravity data with interactive 3D visualization.
- **Daily Capture (APOD)**: Direct synchronization with NASA's Astronomy Picture of the Day protocol.
- **Sonic Observatory**: Authentic NASA sonifications—perceive the audible frequency of gravity and magnetism.
- **Star Atlas**: Detailed constellations and stellar myths that have guided humanity for centuries.
- **Cosmic Search**: Intelligent AI-driven query engine for NASA media archives, asteroids (NeoWs), and space weather.
- **Goldilocks Analysis**: Scientific breakdown of the Habitable Zone and exoplanetary similarity indexes.

## 🛠 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **AI Engine**: [Genkit](https://github.com/firebase/genkit) (Gemini 2.5 Flash)
- **Database & Auth**: [Firebase](https://firebase.google.com/) (Firestore & Firebase Auth)
- **UI Components**: [ShadCN UI](https://ui.shadcn.com/) & [Lucide Icons](https://lucide.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Deployment**: [Firebase App Hosting](https://firebase.google.com/docs/app-hosting)

## 🛸 Getting Started

### 1. Initialize Archive
Clone the mission repository to your local station:
```bash
git clone https://github.com/your-username/quantum-nest.git
cd quantum-nest
```

### 2. Synchronize Dependencies
Install the required archival modules:
```bash
npm install
```

### 3. Configure Credentials
Create a `.env` file in the root directory and populate it with your mission keys:
```env
NASA_API_KEY=your_nasa_key
GEMINI_API_KEY=your_genkit_key
# Firebase config is handled via src/firebase/config.ts
```

### 4. Launch Mission
Start the local development server:
```bash
npm run dev
```
Open [http://localhost:9002](http://localhost:9002) in your browser to begin exploration.

## 🛰 Security & Protocols

- **Archival Hibernation**: Navigation is optimized to only prefetch active mission paths, ensuring high-speed data retrieval.
- **Ownership Privacy**: Personal explorer profiles are strictly sandboxed under path-based security rules.
- **Archival Integrity**: Real-time listeners ensure that mission data is always synchronized with the production backend.
