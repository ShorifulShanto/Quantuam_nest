# 🚀 Quantum Nest | Mission Briefing

Quantum Nest is a high-fidelity, intelligent gateway to the universe. It serves as a unified command center for exploring deep-space archives, planetary libraries, and NASA scientific data through a refined, human-centric interface.

## 🎨 Visual Identity & Color Protocols

The interface uses a specialized archival palette designed for high legibility and atmospheric immersion:

- **Primary Archive Red**: `#E43636` (Used for critical mission protocols, borders, and branding)
- **Archive Parchment**: `#F7F1D6` (Soft background for reduced eye strain during long-duration exploration)
- **Void Black**: `#000000` (Core typography for maximum contrast)
- **Nebula Glow**: `#FFD7C2` (Accents and secondary highlights)
- **Surface Cards**: `#E7E0BF` (Used for archival data containers)

## 🌌 Active Mission Modules

- **Solar System Exploration**: 
  - **3D Eyes**: Real-time interactive visualization of the solar system.
  - **EPIC Grid**: Live synchronization with NASA's Earth Polychromatic Imaging Camera (EPIC) for real-time Blue Marble captures.
- **Cosmic Search**: A Genkit-powered AI query engine that bridges NASA's media archives with intelligent scientific analysis.
- **Daily Capture (APOD)**: Direct protocol synchronization with NASA's Astronomy Picture of the Day.
- **Sonic Observatory**: Real-time access to NASA Sonifications—translating electromagnetic data into audible frequencies.
- **Star Atlas**: A comprehensive guide to the 88 modern constellations, their stellar components, and historical mythologies.
- **Goldilocks Analysis**: Scientific breakdown of the Habitable Zone and Earth Similarity Index (ESI) for exoplanetary candidates.
- **Earth Insights**: Real-time atmospheric, hydrosphere, and geosphere facts.

## 🛠 Engineering Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server Actions)
- **AI Engine**: [Genkit](https://github.com/firebase/genkit) (Gemini 2.5 Flash)
- **Persistence & Identity**: [Firebase](https://firebase.google.com/) (Firestore & Firebase Auth)
- **UI Components**: [ShadCN UI](https://ui.shadcn.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Archival Typography**: Space Grotesk (Headlines) & Inter (Body)

## 🛰 Atmospheric Protocols

- **Infinite Loop Engine**: Background celestial videos play with zero-latency loops and high-priority preloading.
- **Luminosity Guard**: Overlays are tuned to 30% opacity to ensure background vibrancy while maintaining text archival integrity.
- **Path-Based Security**: User discovered "Favorites" are sandboxed under strict Firestore path-level rules.
